# Core Resource Examples

The following remain inside SB Desktop Core because they are needed to make the OS usable without Optional Resources:

- a tiny fallback font/glyph set;
- the default cursor;
- a minimal window chrome;
- minimal settings labels;
- boot/recovery diagnostics;
- minimal terminal/recovery commands;
- resource download error strings;
- the resource cache/index implementation.

The Core version should stay intentionally small. Full visual packs, full locale data, large fonts, high-resolution images, sounds, optional applications, and other user-selected payloads belong in the external Resource Repository.
